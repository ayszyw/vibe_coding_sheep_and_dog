SHEEPDOG DEMO - Windows x64

How to play:
1. Keep sheepdog-demo.exe and the assets folder together.
2. Double-click sheepdog-demo.exe or play.bat.

Controls:
- WASD or arrow keys: move the dog
- Shift: sprint
- Space: bark
- P: pause or resume
- R: restart
- Enter: restart after victory

Replaceable art:
- assets/dog.png: 96x96 transparent PNG, facing up
- assets/sheep.png: 64x64 transparent PNG, facing up
- assets/fence.png: 64x24 transparent PNG, horizontal rail with a post at the left edge

Replace a PNG with another file using the same name. If a file is missing, the game falls back to its built-in drawing.

Requirements:
Windows 10 or Windows 11, 64-bit. No extra runtime installation is required.
